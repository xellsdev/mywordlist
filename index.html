☁️ Conectar con Supabase

Para guardar tus palabras y notas de forma privada, configura tu proyecto gratuito de Supabase:

  1. Crea un proyecto gratuito en Supabase.
  2. Abre el SQL Editor del proyecto y ejecuta el script de configuración de la base de datos.
  3. Copia la URL del proyecto y su clave publicable (anon) desde Project Settings → API.
  4. En Authentication → URL Configuration, configura Site URL y añade a Redirect URLs: https://xellsdev.github.io/mywordlist/.

No introduzcas nunca la clave "service_role". Esta aplicación usa inicio de sesión y políticas privadas por usuario.
